# Documentation

This folder contains project documentation.

API reference details are primarily documented with Doxygen comments in the public headers.
These markdown docs provide additional usage guidance.

The HTML API reference is generated by the `stripekit-docs` build target and written to
`build/docs/html/index.html`. It is generated automatically by standalone builds when
Doxygen is installed. See the "API Documentation" section of the top-level `README.md`
for details. The published reference (for the main branch) is available at
https://keasigmadelta.gitlab.io/stripekit-cpp/. 

Current docs:

- `MainPage.dox`: landing page for the generated reference.
- `Topics.dox`: topic definitions that structure the reference.
- [Overview](Overview.md): supported capabilities and when to use them.
- [Quickstart](Quickstart.md): a worked integration, from build setup to webhooks.
- [Products and Prices](ProductsAndPrices.md): reusable pricing, recovery after
  interrupted requests, and preserving existing subscription prices.
- [Writing an Adapter](WritingAnAdapter.md): supporting a web framework other than Drogon.
- `versioning.md`: versioning policy and release tag format.
- `Doxyfile.in`: Doxygen configuration template used by the `stripekit-docs` target.

New pages and public headers must be added to the lists in
`cmake/doxygen_docs.cmake` to appear in the generated reference.
