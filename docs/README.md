# Documentation

This folder contains project documentation.

API reference details are primarily documented with Doxygen comments in the public headers.
These markdown docs provide additional usage guidance.

The HTML API reference is generated by the `stripekit-docs` build target and written to
`build/docs/html/index.html`. It is generated automatically by standalone builds when
Doxygen is installed. See the "API Documentation" section of the top-level `README.md`
for details. The generated HTML is not checked into the repository.

Current docs:

- `Doxyfile.in`: Doxygen configuration template used by the `stripekit-docs` target.
- `versioning.md`: versioning policy and release tag format.
